# INTERVIEW.md 틀 만들기

## 언제
과제 README를 읽은 직후, 데이터 조사와 인터뷰 전에 한 번. 코드는 쓰지 않는다.

## 순서
1. 작업 폴더에 INTERVIEW.md가 없으면 `assets/INTERVIEW-template.md`를 한 글자도 바꾸지 않고 그대로 복사해 INTERVIEW.md를 만든다.
2. INTERVIEW.md가 이미 있으면 덮어쓰지 않는다.

## 멈추는 곳
"INTERVIEW.md를 만들었습니다." 또는 "INTERVIEW.md가 이미 있어 그대로 두었습니다." 한 줄만 보고하고 멈춘다.

## 하지 말 것
- '물을 것' 칸의 줄을 풀어 쓰기, 뜻을 짐작해 설명하기, 순서를 바꾸기 (사람이 쓰는 메모다)
- README나 데이터를 읽고 질문이나 답을 채우기
- INTERVIEW.md 말고 다른 파일 만들기
